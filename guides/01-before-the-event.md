# 1. Before the event

Thirty minutes this week saves you two hours on Friday night.

## Accounts

- [ ] **GitHub account** for every team member, and your GitHub username in your CodeJam dashboard profile.
- [ ] **[GitHub Student Developer Pack](https://education.github.com/pack)**: apply now, approval can take days.
- [ ] One person on the team has a **free account on the host** you might use (Netlify, Vercel, Render, Hugging Face).
- [ ] If you plan to use a language model API, one account with **a spending limit set**.

## Your laptop

- [ ] [Git](https://git-scm.com/downloads) installed, and `git config --global user.name` / `user.email` set to
      your GitHub details, so your commits count as yours.
- [ ] An editor ([VS Code](https://code.visualstudio.com/) is fine).
- [ ] The runtime you'll use: [Node.js LTS](https://nodejs.org/) and/or Python 3.12+
      (or [uv](https://docs.astral.sh/uv/), which installs Python for you).
- [ ] Clone and run one starter from the [README](../README.md#starters) at home. If it runs, Friday will too.

## Your team

Teams are 3 or 4. If you don't have one, the committee matches you before and during the event.

- [ ] A group chat, and a 15-minute call to share what each person is good at and what they want to learn.
- [ ] Skim the [challenges](02-pick-a-problem.md) and bring two or three problem ideas each. **Don't write project
      code yet**: everything you submit is built after hacking starts on Friday at 19:00.
- [ ] Fill in the [team plan](../templates/team-plan.md) together on Friday.

## What to bring

Photo ID, laptop and charger, the check-in QR code from your dashboard. A power bar and headphones help.
Food is provided all weekend.
